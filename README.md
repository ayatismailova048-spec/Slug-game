# 🐌 Лаборатория слизня

Интерактивная песочница про слизня: его можно измельчить в блендере, поджарить на костре,
растворить в кислоте, помыть в душе, накормить таблетками, обжарить на сковороде и заморозить.
Эффекты **накапливаются и смешиваются**, слизня можно **сохранить** и **выпустить на карту**.

Игра целиком написана на ванильном JavaScript + Canvas 2D. Ни одной внешней библиотеки,
ни одной картинки и ни одного звукового файла: вся графика рисуется кодом, весь звук
синтезируется через WebAudio.

## Как запустить

Просто открой `index.html` в браузере (Chrome, Firefox, Safari, Edge).

Если сохранения не работают из файла `file://`, запусти локальный сервер:

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Управление

| Действие | Как |
|---|---|
| Взять слизня | зажать мышкой/пальцем и тянуть |
| Положить в прибор | перетащить слизня в прибор или кликнуть по прибору |
| Кнопки, вентили, рычаги | клик; вентиль и рычаг — тянуть мышкой |
| Назад в лабораторию | кнопка «Назад» или `Esc` |
| Звук вкл/выкл | кнопка 🔊 в углу или `M` |

## Приборы

| № | Прибор | Что нужно сделать | Что станет со слизнем |
|---|---|---|---|
| 1 | **Блендер** | положить в чашу → закрыть крышку → выбрать скорость → ПУСК | куча ран, деформация |
| 2 | **Костёр** | подбросить 3 полена → чиркнуть спичкой → повесить над огнём | ожоги, волдыри, копоть |
| 3 | **Кислота** | налить кислоту в чан → подвесить на крюк → опустить рычагом | растворяется, видны кости |
| 4 | **Душ** | посадить в ванну → открыть вентиль → выбрать температуру | мокрый и чистый, копоть смывается |
| 5 | **Таблетки** | взять таблетку из аптечки → поднести ко рту | цветные вены, рост/уменьшение, лечение |
| 6 | **Сковорода** | поставить сковороду → налить масло → включить конфорку → дождаться жара → жарить и переворачивать | прожарка, хрустящая корочка |
| 7 | **Лёд** | открыть крышку → положить внутрь → закрыть → ЗАМОРОЗИТЬ | заморожен; мокрый — вмерзает в глыбу льда |

## Комбинации

Эффекты складываются, и у результата появляется своё название:

* мокрый + заморозка → **Слизень во льду** (толстая глыба)
* кислота + костёр → **Обугленный скелет**
* блендер + сковорода → **Котлета по-слизнячьи**
* блендер + 2 таблетки → **Радужный смузи**
* костёр + душ → копоть смывается, идёт пар
* голубая таблетка лечит раны и ожоги и может оживить слизня

## Сохранения и карта

* **Сохранения** — 6 слотов (`localStorage`). Слизня можно сохранить, загрузить обратно
  или сразу выпустить на карту.
* **Карта** — поляна, где живут сохранённые слизни. Их можно перетаскивать мышкой,
  добавлять новых и убирать в корзину. Расстановка сохраняется.

## Как устроен слизень

`SlugModel` хранит эффекты числами от 0 до 1 (`wounds`, `burns`, `melt`, `wet`, `fried`,
`frozen`, `iceBlock`, …). `SlugArt` рисует тело в offscreen-буфер слоями: заливка → таблеточные
вены → корочка → ожоги → раны → волдыри → кости → капли → иней, затем вырезает дыры от кислоты
(`destination-out`), рисует глаза на стебельках и, если надо, глыбу льда сверху.
Поэтому любые эффекты сочетаются между собой в любом порядке.
